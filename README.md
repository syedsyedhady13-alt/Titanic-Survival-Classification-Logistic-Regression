# 🚢 Titanic Survival Classification — Logistic Regression

A machine learning classification project that uses Logistic Regression
to predict whether a Titanic passenger survived based on passenger and
travel information.

## 📌 Overview

This project uses the Titanic dataset to build a binary classification
model for predicting passenger survival.

The project covers the complete basic machine learning workflow:

- Dataset exploration
- Data cleaning
- Feature selection
- Handling missing values
- Removing duplicate records
- Categorical encoding
- Feature scaling
- Train/test splitting
- Logistic Regression training
- Model evaluation
- Interactive passenger prediction

## 🧠 Machine Learning Task

### Binary Classification

The model predicts one of two outcomes:

- `0` — Did not survive
- `1` — Survived
